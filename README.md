# Эхо-Цитадель — коллекционная карточная игра

Фэнтезийная ККИ в духе MTG / Hearthstone с двумя авторскими механиками:
**Руны** (постоянные глобальные правила) и **Эхо-очки** (бесплатное повторение
последнего заклинания, если в ход не разыграно ни одного заклинания).

Целевая платформа — **Unity 2022.3 LTS (C#)**. Разработка ведётся от
**движка правил на TypeScript**: сначала правила и баланс проверяются
симуляцией десятков тысяч матчей и играбельным HTML-прототипом, затем
тот же контракт переносится в C# один-в-один.

Управляющий документ — техническое задание заказчика. Все отклонения от него
зафиксированы в [`docs/ADDENDUM_passives.md`](docs/ADDENDUM_passives.md).

## Быстрый старт

```bash
npm i                     # typescript, esbuild, jsdom (dev-зависимости)
                          # NB: node_modules не входит в снимок рабочей области —
                          # после перезапуска песочницы npm i обязателен перед сборкой

# 1. Сгенерировать 150 карт + 6 колод (пишет в Unity StreamingAssets)
python3 tools/generator/generate_cards.py

# 2. Собрать и прогнать автотестер баланса (ТЗ п.8.1, 10 000 матчей)
npx esbuild tools/balance/run_balance.ts --bundle --platform=node --outfile=build/run_balance.js
node build/run_balance.js --matches 10000 --seed 20260903

# 3. Играть в браузере
npm run build:proto && npm run proto      # → http://localhost:5173/
# ВАЖНО: prototype/prototype.css — КОПИЯ при сборке; править только src/ui/prototype.css

# 4. Headless-проверка прототипа (jsdom, 58 утверждений)
npm run smoke

# 5. Проверка C#-порта движка (нужен .NET SDK 8; в песочнице — ~/.dotnet)
npm run build:cs     # только сборка ядра
npm run verify:cs    # сборка + 82 сверки с эталоном, снятым с TypeScript
```

## Ключевые правила (коротко)

- MTG Constructed: минимум **60** карт, без верхнего лимита и сайдборда, до **4** копий любой карты (включая легендарные); герой **30** HP, стартовая рука **5**, муллиган **1** раз за игру.
- Мана: максимум **+1** каждый ход до **10**, полное восполнение в фазу «Ресурсы».
- **5 фаз хода**: Начало → Ресурсы → Основная → **Битва** → Конец.
- **Битва автоматическая**: каждое готовое существо бьёт существо противника
  с наименьшим здоровьем (сначала с Провокацией), иначе — героя. Урон обоюдный.
- На доске не более **7** существ и **3** рун; копия руны запрещена.
- **Руны** не уничтожаются обычными заклинаниями (эффекты уничтожения и возврата
  в руку действуют только на существ). **Ритуалы** разрешаются в начале следующего хода.
- **Эхо-очко** начисляется в конце хода, если за основную фазу не разыграно
  ни одного заклинания; тратится один раз за игру на бесплатное повторение
  последнего заклинания.
- Пустая колода → **усталость** (растущий урон за каждый добор).

Полный текст правил и пассивок — в прототипе (кнопка «Правила и пассивки»)
и в `docs/ADDENDUM_passives.md`.

## Архитектурный принцип (важно для порта)

**Движок синхронный и детерминированный, представление — асинхронное.**
Никакой игровой логики в UI-слое: контроллер лишь вызывает методы движка
и проигрывает события/очереди, которые движок подготовил.

Пример — фаза «Битва»: движок просчитывает её целиком и складывает план атак
в `attackQueue` (включая состояние атакующего и защитника **до** удара),
а UI проигрывает план по одной атаке. В Unity это ложится в
`CombatPresenter` поверх `GameEngine.AttackQueue` как DOTween-последовательность.

Соответствие модулей прототипа и целевых C#-скриптов — в
[`prototype/README.md`](prototype/README.md), таблица «Соответствие кода прототипа и будущего порта».
