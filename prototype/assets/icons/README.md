# Значки разделов верхней панели (v3.10)

Положите сюда PNG с прозрачным фоном (квадрат, рекомендуемо 96×96 или 128×128).
Пока файла нет — показывается встроенный контурный SVG-значок. Перезагрузите страницу — PNG подхватится сам.

| Файл | Раздел |
|---|---|
| home.png | Главная |
| collection.png | Коллекция |
| decks.png | Колоды |
| packs.png | Бустеры |
| store.png | Магазин |
| events.png | События |
| campaign.png | Кампания |
| online.png | Сетевая игра |
| mastery.png | Боевой пропуск |
| quests.png | Задания |
| rules.png | Правила |
| tutorial.png | Обучение (малый значок справа) |
| settings.png | Настройки (малый значок справа) |
| exit.png | Выход (малый значок справа) |

Значок отображается 30×30 (малые — 24×24); активный раздел подсвечивается золотом автоматически.
Примечание: в .gitignore есть `*.png` — для коммита используйте `git add -f`.
