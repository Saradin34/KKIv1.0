# Логотип (v3.10)

`logo.png` — логотип для верхней панели, прозрачный фон, горизонтальный (рекомендуемо ~600×160).
Высота на экране ≈ 52 px (десктоп) / 40 px (мобилка), ширина ограничена 240 px.
Пока файла нет — показывается текстовый логотип «ECHO CITADEL». Клик по логотипу — на главную.
Для коммита: `git add -f prototype/assets/ui/logo.png` (в .gitignore есть `*.png`).
