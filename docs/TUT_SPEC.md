# СПЕЦИФИКАЦИЯ «6. 🎓 ОБУЧЕНИЕ» — реализация v2.5.1

Дата: 2026-09-21. Треки: HTML-прототип (?v=2.5.1) + meta_server (:8081) + Unity C# (некомпилированный).
База: интерактивные уроки существовали с v2.x (4 урока с гейтом хода); v2.5.1 доводит их до спеки — **20 пошаговых шагов с подсветкой и блокировкой посторонних действий**, обновляет урок 3 под ключевые механики спеки и гейтит тренировку.

## 1. Пошаговые уроки (п.6.1) — 20 шагов × 4 урока

Скрипт шагов — единый для прототипа (`TUT_STEPS`) и Unity (`StreamingAssets/tutorial.json`, формат из Промпта 2: `{id, message, highlight, required_action, next_step}` + `lesson`, `next_step=0` = урок завершён, `on_complete:"reward"` у шага 20).

| Урок | Шаги | Содержание |
|---|---|---|
| 1 · Основы | 1–5 | Руна «Обетный монолит» (1✦) → существо **«Ветеран Осады»** (neu_03, 3✦) → заклинание «Луч Рассвета» (1✦) → завершить ход → закрепить |
| 2 · Бой | 6–10 | Призыв «Послушника Света» (Провокация ⛨) → атака (клик свое существо → цель) → ход врага бьёт в провокатора (**блок**) → добить урок |
| 3 · Ключевые механики | 11–15 | **Вампиризм** 🩸 «Упырь-мародёр» (nec_03) → атака с лечением героя → **Неуловимость** 👁 «Эфирный разведчик» (eth_01, spec-«Неуязвимость»: нельзя выбрать целью) → **Боевой клич** ✦ «Рассветный капеллан» (aur_03) |
| 4 · Ресурсы | 16–20 | **Кривая маны**: клик «Серафима Зари» (5✦) — маны не хватает (объяснение) → дешёвая карта (1✦) → ход → ещё 2 карты → финал с on_complete=reward |

Механика движка шагов (прототип):
- **Заскриптованная рука**: `TUT_HANDS` инжектирует карты урока в стартовую руку (`engine.p(Player).hand.push`), **муллиган в уроках пропущен** (`showMulligan` early-return).
- **Подсветка**: `.tourHi` (золотой контур) на `hi()`-элементе шага; поллер 350 мс возвращает подсветку после перерисовок.
- **Тренер**: `#tutCoach` — «Урок N · шаг X/20 — сообщение».
- **Ожидание действия**: предикат `ok()` на статах движка (runesPlayed/creaturesSummoned/spellsCast/damageDealt/healingDone/cardsPlayed/turn) + метки шага (tutMark/tutMarkCards/tutMarkDmg) и флаг клика (tutTap — урок 4).
- **Блокировка** (Промпт 1 п.4): capture-блокеры click/dragstart — вне `allow`-селекторов шага действие отменяется + тост; всегда разрешены «Меню» (анти-softlock), тренер, тосты. Гейт «Завершить ход» (`tutOk`) сохранён: L1 руна+существо+**заклинание**, L2 урон, L3 **все три** механики, L4 3+ карты к 3 ходу.
- Награды уроков однократные (`meta.tutClaims` — анти-фарм повторных прохождений): ◈100/◈100/◈150/◈100.

## 2. Награда (п.6.2)

После 4 уроков в хабе «🎓 Обучение» — **выбор фракции** (5 кнопок) → `grantTutReward`: 10 дешевейших базовых карт фракции ×2 (стартовая колода) + **5 бустеров** (freeOpens) + 💎100. Одноразово (`meta.tutReward`).

## 3. Тренировка (п.6.3)

`chkPractice` («Тренировка — без влияния на рейтинг») **disabled до прохождения обучения** (`tutGatePractice()` — boot/после урока/после награды); кнопка-подсказка в хабе до обучения отвечает тостом «откроется после обучения». Матчи уроков и тренировки — unranked (`practice || campaignBoss || tutLesson`).

## 4. Сервер (meta_server :8081) — live 10/10

## 5. Unity C# (не скомпилировано)

- **`StreamingAssets/tutorial.json`** (Промпт 2) — 20 шагов точного формата спеки (см. §1); сообщения 1-в-1 с прототипом.
- **`TutorialController.cs`** (Промпт 1): загрузка JSON (`TutorialFile/TutorialStep` DTO); реестр подсветки `RegisterHighlight(key, go)` (ключи: hand_rune/hand_veteran/hand_spell/hand_taunt/hand_lifesteal/hand_unblockable/hand_battlecry/hand_expensive/hand_cheap/hand_any/board_own_creature/board_own_taunt/board_own_lifesteal/btn_end_turn) + фолбэк `GameObject.Find`; блокировка полноэкранным blocker'ом, подсвеченный объект поднимается `Canvas.overrideSorting = blockerOrder+1` (клики доходят только до него); ожидание действия: `NotifyAction(action, cardId)` + шины `GameEvents.OnCardPlayed`, публичные `NotifyAttack/NotifyEndTurn/NotifyPlayerTurnStart/NotifyTap`; «Отменить урок» всегда кликабельна (анти-softlock); завершение урока → POST complete → авто-старт следующего; после урока 4 → панель награды (5 кнопок фракций) → POST reward → `PlayerPrefs ec.tut.done=1` + `TrainingUnlocked` + событие `OnTutorialCompleted`; события `OnStepChanged/OnLessonCompleted`; тосты/звук (stepClip/rewardClip).
- Интеграция: бой вызывает Notify* из фаз; карты руки регистрируют подсветку при раздаче (объекты пересоздаются); `TrainingUnlocked` гейтит кнопку «Тренировка» в меню.

## 6. Отклонения и решения (документированы)

1. «Неуязвимость» из спеки → keyword **Unblockable** («Неуловимость: нельзя выбрать целью») — ближайшая существующая механика; отдельного keyword «неуязвимость» в 300 карт нет.
2. «Блокирует» (урок 2) → блок через **Провокацию**: движок не даёт объявлять блокеров вручную (HS-модель: taunt перехватывает атаки) — шаг 9 показывает это на живом бое.
3. Карты уроков захардкожены id'ами (детерминированно), а не поиском по ключевым словам (эвристика v2.x заменена): aur_r07/neu_03/aur_s01 · aur_01 · nec_03/eth_01/aur_03 · aur_09/aur_01.
4. Награда урока 4 в хаб-таблице «💎100 + 5 бустеров» фактически выдаётся финальным выбором фракции (п.6.2) — как в v2.x, без изменений.
5. Блокировка в прототипе — capture-перехват click/dragstart с тостом (мягкая); «Меню» всегда доступно. В Unity — жёсткий raycast-blocker.
