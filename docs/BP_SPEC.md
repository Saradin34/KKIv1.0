# СПЕЦИФИКАЦИЯ «5. 🎟️ БОЕВОЙ ПРОПУСК» — реализация v2.5.0

Дата: 2026-09-21. Треки: HTML-прототип (?v=2.5.0) + meta_server (:8081) + Unity C# (некомпилированный).
Решения пользователя (binding): **«альтернативные арты» → фойл-карты** (жетон применяется к любой своей карте); **«редкие бустеры» → премиум-бустер 2C+1R+2E/L**; **XP унифицирован: победа +120 / поражение +60 во всех режимах** (скидка за нерейтинг отменена).

## 1. Прогрессия (п.5.1)

- **50 уровней**, **400 BP XP на уровень** (`BP_STEP`; уровень = floor(xp/400)+1, кап 50).
- Ставки XP: победа **+120**, поражение **+60**, ежедневное задание **+150**, недельное **+250** (`BP_XP` на сервере — авторитет; клиент зеркалит).
- Отображение: прогресс-бар **до следующего уровня** (xp%400/400, на капе — 100%), текущий уровень подсвечен (`.bpLvl.cur` — золотое ядро + пульсация `bpCur`), счётчик «до следующего: X/400».
- Сезон 30 дней (`SEASON_MS`): по истечении — сброс bpXp/веток/премиума (фойл-жетоны, премиум-бустеры в запасе и полученная косметика СОХРАНЯЮТСЯ — это инвентарь).

## 2. Таблица наград (п.5.2/5.3)

Free (всем): ◈ = золото/пыль (единая валюта, решение §3) — каждый уровень `◈50+lvl*3`; каждый 10-й — бустер ECH1; 50 — бустер ×2.

## 3. Новая механика

- **Фойл-жетон** (`meta.foilTokens` / `gp.foilTokens`): в модалке карты кнопка «🌟 Фойл (жетонов: N)» — требует владения картой, жетон тратится, `foils.set(id,+1)` (кап 4 фойла на карту). Фойл из бустеров (20% на пачку) — без изменений.
- **Премиум-бустер** (`meta.premOpens` / `gp.premOpens`): состав **2C+1R+2 слота эпик+** (каждый 12.5% легендарка), пул — расширение ECH1, фойл 20%, playset-конверсия в ◈. В модалке бустера — вторая кнопка «🌟 Премиум-бустер (в запасе: N)». Клиент: `drawPremiumBooster()` = `drawBooster(undefined, comp)`; сервер: `rollPack(null, premium=true)`.
- **Аватар «Лунный Архонт»** (`lunar`, глиф ☾): `avatarsOwned.push('lunar')` + запись в `PREMIUM_AVATARS` (рядом с arch/lich).
- **«Забрать всё»** (п.5.4): клеймит все доступные (free + prem при активном премиуме) и показывает **суммарный итог**: «Забрано наград: N — ◈X · 💎Y · бустеры ×Z · 🌟 премиум-бустеры ×P · фойл-жетоны ×F · рубашки ×B · аватары ×A».

## 4. Сервер (meta_server :8081) — live 20/20

| Эндпоинт | Тело | Семантика |
|---|---|---|
| `GET /api/battlepass?pid` | — | `{levels:50, xpStep:400, rates, xp, level, premium, claimedFree[], claimedPrem[], rewards[50]{lvl,free,prem}}` |
| `POST /api/battlepass/addxp` | `{pid, reason\|amount}` | reason: win/loss/daily/weekly → ставка сервера; 400 без reason/amount; 200 `{xp, level, levelUps, newLevels[]}` |
| `POST /api/battlepass/buy` | `{pid}` | премиум 💎500: 402 мало гемов, 409 уже активен; 200 `{premium, gems}` |
| `POST /api/battlepass/claim` | `{pid, level, track}` | track free\|prem; 400 невалидно, 403 prem без премиума, 409 не достигнут/уже получена; 200 `{reward, shards, gems, freeOpens, premOpens, foilTokens}` |
| `POST /api/battlepass/claimall` | `{pid}` | 200 `{claimed, totals{shards,gems,packs,premPacks,foils,backs,avatars}, кошельки}` |
| `POST /api/packs/open` | `{pid, type}` | type free\|premium: списывает freeOpens/premOpens (402 нет запаса), 200 `{drops[5]}` → регистрировать через `/api/collection/add` |

GameProfile расширен: `bpXp, bpPremium, bpClaimed[], bpClaimedP[], foilTokens, premOpens, avatarsOwned[]`; `POST /api/profile` принимает их от `syncProfile` (зеркало прототипа). Награды-косметика идут в `purchases` (`back_abyss/back_verdant`) — магазин при попытке покупки выдаст 409 «already owned», БП-витрина (currency:'bp') остаётся непродаваемой (403).

## 6. Unity C# (Assets/Scripts/UI/) — не скомпилировано

- **`BattlePassController.cs`** (Промпт 1): GET /api/battlepass → DTO `BpState` (rewards[50]); лента 50 уровней (ScrollRect + префаб bpLevel: «Level»/«Free»/«Prem»/«BtnFree»/«BtnPrem»/«Cur»), автопрокрутка к текущему; «Забрать» → POST claim {level,track}; «Забрать всё» → POST claimall → тост-итоги; «Премиум 💎500» → POST buy; ошибки → тост; события `OnLevelChanged/OnRewardClaimed/OnPremiumBought`; прогресс-бар fillAmount = xp%xpStep/xpStep.
- **`BattlePassXP.cs`** (Промпт 2): подписка `GameEvents.OnMatchWin(win,ranked,fac)` → reason win/loss; `GameEvents.OnQuestComplete(questId,kind)` → daily/weekly; POST /api/battlepass/addxp {pid,reason} (ставки знает сервер); ответ `levelUps>0` → `PlayLevelUp`: levelUpFx (SetActive + Animator-триггер «LevelUp», автоскрытие) + AudioSource.PlayOneShot(levelUpClip) + статик-событие `OnBpLevelUp(newLevel)`; опц. ссылка `passController.Reload()`.
- **`QuestSystem.cs`** (правка): в шину добавлено `OnQuestComplete(questId, kind)` + публикация `GameEvents.QuestComplete(...)` в `Claim()` после успешного клейма (заменяет прежний «только лог» BP XP).
- Интеграция: BattlePassController + BattlePassXP на UIRoot в Main.unity; `baseUrl` = адрес meta_server; бой публикует `GameEvents.MatchWin(win, ranked, faction)`.
