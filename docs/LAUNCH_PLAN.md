# «Эхо-Цитадель» — план запуска (soft launch → Steam)

Версия 1.0 · 2026-09-21. Статус продукта: играбельный прототип (HTML) + серверная часть
(match-server WS :8080, meta-server REST :8081) + Unity-заготовки (Cards.json 300 карт,
CardDataSO-генератор). Баланс подтверждён симуляцией 10 000 матчей: все фракции 45–55%.

## 0. Принципы

- **No pay-to-win**: монетизация только косметика (рубашки, фойл-эффекты, рамки). ◈ зарабатываются
  игрой; бустеры — единственный источник карт вне базовых ~150 (правило прогрессии v1.6).
- **Loot-box transparency**: публикуем шансы дропа бустера (3C+1R+1E, L/R 12.5%) в UI магазина —
  требование Steam и регуляторов (ESRB/PEGI/Указ 210-ФЗ РФ о раскрытии шансов).
- Все продуктовые решения — по данным телеметрии (раздел 4), а не по ощущениям.

## 1. Этап A — закрытая альфа (50–100 игроков, 2–3 недели)

**Цель:** техническая стабильность + честность экономики, не маркетинг.

| Что | Как |
|---|---|
| Набор | Личные приглашения: CCG-сообщества (Telegram/Reddit r/TCG, форумы MTG-альтернатив), 50–100 человек |
| Доступ | Web-прототип по ссылке + аккаунт meta-server (profiles.password_hash уже в schema.sql) |
| Сборка | Docker Compose: nginx → prototype static, match-server, meta-server, PostgreSQL (DEPLOYMENT.md §7) |
| Телеметрия | match_card_events (played/stuck по ходам), duration_seconds, v_card_winrate — schema.sql готов |
| Дашборды | Metabase/Grafana поверх PG-вью (tools/make_dashboard.py описывает панели); офлайн — CSV-дашборд |
| Баг-репорт | Форма в игре + Discord-канал; критичные баги — стоп альфы и хотфикс |

**Метрики альфы и пороги успеха:**
- Краш-рейт / обрыв WS-сессий < 2%;
- Медианная длина матча 8–16 ходов (сейчас сим: 12.0 — норма);
- «Застревающие» карты (stuck-телеметрия): нет карты с stuck-rate > 60% — иначе nerf_proposals.md → apply → ре-симуляция;
- Винрейты фракций на живых данных в 45–55% (не только в симах!) — расхождение сим/живых > 5 п.п. = пересмотр AI-профилей;
- Опрос NPS после 5+ матчей ≥ 30.

**Баланс-контур альфы (data science, уже построен):**
`npm run balance` (10k сим) → `npm run autonerf` (docs/balance/nerf_proposals.md, НИКОГДА не
авто-apply без ревью) → правка Cards.json → повторная симуляция → коммит CSV+JSON вместе.
Живая телеметрия сверяется с сим-винрейтами еженедельно через `v_card_winrate`.

## 2. Этап B — региональный soft launch (4–8 недель)

**Регион:** RU/BY + KZ (кириллица родная, локаль ru.json заполнена; en.json — полный
перевод 500 карт + 7 токенов + ядро UI, готов ко второй волне). Платформа: web
(PvP-матчмейкинг через match-server).

**Цель:** retention и экономика на сотнях игроков, до маркетинговых spend.

| Метрика | Цель soft launch | Стоп-порог |
|---|---|---|
| Retention D1 | ≥ 35% | < 25% → переработка онбординга (тур/кампания) |
| Retention D7 | ≥ 15% | < 10% → пересборка прогрессии (темп ◈/бустеров) |
| Retention D30 | ≥ 6% | < 4% → отсрочка Steam-релиза |
| Средняя сессия | ≥ 12 мин | — |
| Матчей/DAU | ≥ 2.0 | — |
| Конверсия free→battle pass активности | ≥ 40% игроков до 5 уровня BP | — |
| Жалобы на баланс (топ-фракция пикрейт) | пикрейт фракции ≤ 30% | > 40% → экстренный нерф-контур |

**Инфраструктура soft launch:** PG с бэкапами (pg_dump cron), rate-limit на meta-server,
античит-минимум: серверная валидация экономики уже есть (◈/крафт/пыль — только через REST),
логика боя — доверяем клиенту в прототипе, но история матчей пишется сервером (match_history).

**Итерации:** 2-недельные спринты; каждый спринт — баланс-патч (по autonerf + живой телеметрии),
1 контент-пак (кампейн-босс / сезон BP / рубашки), отчёт devlog.

## 3. Этап C — маркетинг и Steam (параллельно с B, релиз после порогов retention)

1. **Devlog-кадр:** еженедельные посты (itch.io devlog + Reddit r/IndieGaming, r/TCG, VK/Telegram):
   «как мы сделали LIFO-стек», «10 000 симуляций баланса», «дальтоник-режим» — инженерные темы
   хорошо заходят в CCG-аудитории. Скриншоты/гифки — из прототипа (арт карт уже пайплайнится).
2. **Steam-страница:** открыть за 2–3 месяца до релиза ради wishlist'ов. Цель wishlists до релиза:
   7 000+ (порог заметного алгоритмического буста Steam). Теги: CCG, Card Game, Strategy, Fantasy,
   PvP, PvE, Singleplayer. Возрастной рейтинг: IARC → учёт лутбоксов (шансы раскрыты → обычно 12+).
3. **Ключи инфлюенсерам:** 50–100 ключей CCG-стримерам (Hearthstone/MTG-сегмент); фокус —
   «MTG-глубина (стек, инстанты) + быстрый PvE-вход».
4. **Демо на Steam Next Fest:** собрать PvP-нарезку из match-server; участие = всплеск wishlists.
5. **Портирование в Unity (BLOCK 2):** к Steam-релизу нужен C#-порт движка (сейчас на паузе —
   движок TS ушёл вперёд: стек LIFO, lookahead-AI). План: повторный автоматический порт
   engine.ts → C# после стабилизации правил (freeze фич за 6 недель до релиза).

## 4. Телеметрия — что именно собираем (готово в прототипе)

- Каждый живой матч: фракция, победа, ходы, **duration_seconds**, все розыгрыши карт
  (**played: [cardId, turn]**) и **stuck** (карты, умершие в руке) — meta.telem (localStorage,
  кап 40 матчей) → при наличии аккаунта отправляется на сервер в `match_card_events`;
- `v_card_winrate` (PG-вью): winrate при розыгрыше + средняя длина — источник для Metabase/Grafana;
- Профиль игрока в игре показывает ему же агрегаты (средняя длина, топ застревающих) — прозрачность;
- Авто-предложения: `tools/autonerf.py` → `docs/balance/nerf_proposals.md` (только предложения,
  применение ручное + обязательная ре-симуляция 10k).

## 5. Риски и mitigation

| Риск | Mitigation |
|---|---|
| Дисбаланс на живых данных (сим ≠ человек) | Недельная сверка v_card_winrate с сим-CSV; nerf-контур |
| Отток из-за темпа прогрессии | BP-трек + daily-квесты уже дают ◈; A/B темпа бустеров в soft launch |
| Регуляторика лутбоксов (RU/ЕС) | Раскрытие шансов в UI, косметика-only монетизация, возраст 12+ |
| C#-порт отстаёт от TS-движка | Стек LIFO + lookahead портированы (2026-09-24); verify.sh headless зелёный; фич-freeze перед Steam |
| Один регион = один язык | en.json заполнен (1533 ключа, 500 карт + токены + UI); переключатель ru/en в Настройках |
