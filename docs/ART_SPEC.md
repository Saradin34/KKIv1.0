# ЭХО-ЦИТАДЕЛЬ — СПЕЦИФИКАЦИЯ АРТОВ (для генерации изображений)

## 1. Карта — точные размеры
| Параметр | Значение |
|---|---|
| Файл-оригинал | **512×720 px, PNG** (пропорция 0.7111; рамка 190:266 = 0.7143 — расхождение <0.5%, кроп нулевой) |
| Рамка карты | кант 3 px + внутренняя фаска 2 px и 4 px, радиус 10 px (в css-px эталона 190×266) |
| Арт | full-bleed: лежит под всеми пластинами, видимая часть — окно ниже |
| **Видимое арт-окно** | **y 72–504 px** (10–70% высоты), полная ширина 512 px |
| Скрыто интерфейсом | y 0–72 (пластина имени), y 504–677 (типовая линия + пергамент текста), y 677–720 (нижняя кромка/P-T) |
| Безопасная зона сюжета | **x 41–471, y 101–475** (лицо/фокус композиции здесь) |
| Фокус кадрирования | object-position 50% 38% → центр сюжета примерно **(256, 274)** |
| Цветовой кант рамки | задаётся интерфейсом по фракции (художнику не нужен): Aur #c9a23f, Nec #8a4aa8, Ter #5f8a3a, Pyr #c05a1a, Eth #2a9a90, Neu #8a9199 |

Шаблон с зонами: `_processed/templates/card_template_512x720.png`
(зелёный контур — видимое окно, жёлтый — безопасная зона, красный крест — фокус,
тёмные полосы — то, что закроют пластины имени/типа/текста).

## 2. Герой (аватар фракции)
| Параметр | Значение |
|---|---|
| Файл | **512×512 px, PNG** |
| Кроп интерфейса | круг-медальон (диаметр 84–120 px в бою, 60–104 px в меню) |
| Безопасный круг | лицо/эмблема внутри центрального круга r≈200 px, фокус лица ~ (256, 230) |
Шаблон: `_processed/templates/hero_template_512x512.png`

## 3. Куда класть
- Карты: `art_raw/<id>.png` (id из Cards.json: `aur_01`, `nec_s12`, `ter_r07`…) — обе drop-зоны:
  `echo-citadel/art_raw/` и `/home/user/art_raw/`. Прототип подхватывает сразу.
- Герои: `art_raw/heroes/<Faction>/<любой файл>.png` (Aurites, Necrus, Terramorph, Pyromancer, Ethereal).
- Нормализация: `npm run art:process` приводит всё к 512×720 / 512×512 (cover-crop, фокус 38%),
  раскладывает в `_processed/` и `Assets/Resources/`; идемпотентно по sha256.

## 4. Размеры отображения (справочно, генерировать под них НЕ нужно)
Рука 150–196 px шириной, поле 100–142, коллекция 158–190, модалка 300–380, пак 122–164 —
все поверхности масштабируют один и тот же файл 512×720; на ретине-модалке запас ×1.4.
