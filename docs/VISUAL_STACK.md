# Визуальный стек «Эхо-Цитадель»

Решение заказчика: **ориентир — MTG Arena и Hearthstone**. Отсюда зафиксированная
презентация и состав ассетов.

---

## 0. Что именно мы берём у Arena и у Hearthstone

| Источник | Берём | Не берём |
|---|---|---|
| **MTG Arena** | Доска как **материал**: 3D-плоскость стола (камень/кожа) с PBR-текстурой, наклонённая камера ~50°, существа = **2D-карты-квады** на столе (не модели), зоны подсвечиваются декалями, DoF размывает дальний край, UI — слой поверх | — |
| **Hearthstone** | **Отклик**: карта «живая» под курсором (подъём, наклон, блик), тяжёлый звук + VFX на каждое действие, тряска экрана на большом уроне, «вкусные» смерти, читаемый силуэт числа атаки/здоровья | **3D-модели миньонов** и их анимации скелета/idle |

**Почему не берём 3D-модели существ (как в HS):** у нас 75 существ + 7 токенов.
Это 82 модели, риг, idle/attack/death-анимации и пайплайн — месяцы работы и бюджет,
несопоставимый с остальной игрой. При этом у нас уже есть **150 единиц живописного
2D-арта 512×720** (`docs/art_prompts.csv`), и Arena доказывает, что 2D-существа
на 3D-столе выглядят «дорого» при правильных материалах, свете и VFX.

**Итог: 2.5D.** 3D-стол + наклонённая камера + 2D-квады карт/существ + 3D-VFX
поверх стола + UI отдельным слоем. Это даёт настоящую глубину (DoF, Bloom, декали,
параллакс) без стоимости 3D-пайплайна персонажей.

## 1. Сцена, камера, масштаб

Мир в «единицах карты». Карта 512×720 px, в мире — **1.0 × 1.4** unit.

| Параметр | Значение | Обоснование |
|---|---|---|
| Размер карты-существа на столе | 0.72 × 1.0 (72% от полной карты) | Arena показывает на столе уменьшенную карту |
| Ширина стола | 5.6 | 7 существ × 0.8 шаг |
| Глубина стола | 6.4 | два ряда + руны + герои |
| Камера | Perspective, **FOV 32** | низкий FOV = почти ортографика, но с живой глубиной |
| Позиция камеры | `(0, 5.4, -5.2)` | ~46° к столу |
| Точка фокуса | `(0, 0, 0.55)` | центр стола со сдвигом к игроку |
| Наклон камеры | `LookAt` → `rotation ≈ (46.1°, 0, 0)` | |
| Рендер-масштаб | 1.0, **MSAA 4x**, HDR on | HDR обязателен для Bloom с порогом > 1 |
| UI-камера | Screen Space – Camera, distance 1.0, рендерится **после** Volume | иначе зерно и Bloom лягут на текст |

### Слои (Layer / Sorting)

```
0  Background    — задник-циклорама (HDRI или живописный квад), туман
1  Table         — плоскость стола, декали рун/ритуалов/прицелов
2  Units         — квады существ и карт на столе (sorting по Z ряда)
3  VfxUnder      — наземные VFX: круги призыва, трещины, рябь
4  VfxOver        — снаряды, всплески, искры, душ-виспы
5  UI            — рука, панели, лог, кнопки (Screen Space – Camera)
6  UiOverlayFx   — вспышки экрана, виньетка-пульс, глитч (поверх UI)
```

| Деколь | Когда |
|---|---|
| Круг руны (золотой глиф-ринг) | под каждой из ≤3 рун; пульсирует раз в ход на стартовой фазе |
| Тикающий круг ритуала | на месте ритуала, деления гаснут по ходу задержки |
| Прицел-ретикла | под целью при drag&drop; золотая для своих, янтарная для врагов |

## 4. Пост-обработка (URP 14 Volume Framework)

В Unity 2022.3 LTS пост-обработка **встроена в URP** — отдельный Post-Processing
Stack не нужен и не совместим. Профиль: `Assets/Settings/PostFX_Citadel.asset`.

| Эффект | Значение | Зачем |
|---|---|---|
| Tonemapping | **ACES** | плёночный ролл-офф, убирает плоскость |
| Color Adjustments | Post-exposure `+0.15`, Contrast `+14`, Saturation `+8` | плотность |
| White Balance | Temp `−6`, Tint `+3` | холодный камень vs тёплое золото |
| Split Toning | Shadows `#2A2438` @0.35, Highlights `#D8B45A` @0.22 | фирменная пара |
| Bloom | Intensity `0.55`, Threshold `1.05`, Scatter `0.62`, Tint `#FFE6B0` | светятся только руны/мана/Эхо |
| Vignette | `0.30`, Smoothness `0.42`, Color `#05060A` | сборка кадра к центру |
| Film Grain | Response, Intensity `0.16`, Size `0.9`, LumContrib `0.7` | «живая» поверхность, убирает бэндинг |
| Chromatic Aberration | `0.12` постоянно, всплеск `0.6` на 0.25 с при уроне герою | микро-аберрация = дорого |
| Depth of Field | **Gaussian**, Start `6.0`, End `18.0`, Max Radius `3` | рука и центр стола резкие, дальний герой и кромки мягкие |
| Motion Blur | `0` | в ККИ вредит читаемости |
| Lens Distortion | `0` | ломает точность drag&drop |

Renderer Features: **Decal** (стол), **Render Objects** (слои VfxUnder/VfxOver/UiOverlayFx).

## 5. Материалы карт и существ

База — **All In 1 Sprite Shader** (URP 2D). Нужные нам фичи и где они применяются:

| Фича шейдера | Применение |
|---|---|
| Outline | подсветка допустимых целей (золото — свои, янтарь — враги), пульс 1.2 Гц |
| Holographic / Gradient ramp | фойл по редкости: Rare — сатин, Epic — перелив, Legendary — анимированное золото |
| Radial / Radium dissolve | смерть существа, сгорание карты при усталости |
| Reveal (radial) | выход существа на поле |
| Rim light | подсветка края при наведении |
| Wobble / Hit shake | удар в ближнем бою |
| Inner shadow + Drop shadow | карта «лежит» на столе, а не наклеена |
| Specular highlight от курсора | «живой» материал под указателем (как в Arena) |

Поведение (DOTween):

- **Наведение:** `DOLocalRotate(-14°, 0, 0)` + `DOScale(1.06)` + `DOLocalMoveY(+0.12)`, 0.14 с, `OutQuad`;
- **Drag:** карта летит к столу как 3D-объект, под целью разворачивается декаль-ретикла;
- **Розыгрыш:** `DOMove` к слоту 0.22 с → вспышка (emissive ×3 на 0.1 с) → radial reveal;
- **Веер руки:** как в Arena — поворот до ±24°, подъём по косинусу, перекрытие, z-order по индексу.

## 8. Эквиваленты в HTML-прототипе

Прототип показывает тот же визуальный язык без Unity, чтобы заказчик видел результат
до порта, а порт был переносом, а не переизобретением.

| Unity | Прототип (CSS/SVG/Canvas) |
|---|---|
| Volume: Tonemapping/Split Toning | палитра CSS-переменных (тень `#2A2438` / свет `#D8B45A`) |
| Bloom | `box-shadow`/`filter: drop-shadow` c HDR-подобными цветами + `mix-blend-mode: screen` |
| Vignette | слой `radial-gradient` + `mix-blend-mode: multiply` |
| Film Grain | SVG `feTurbulence` в оверлее, `opacity .06`, анимация `seed` |
| Chromatic Aberration | три копии `drop-shadow` по R/G/B на 1–2 px + `filter: url(#aberr)` |
| Depth of Field | `filter: blur()` на дальнем ряду и кромках стола |
| Тепловое марево | SVG `feTurbulence` + `feDisplacementMap` |
| Decal (круги, прицелы) | абсолютно позиционированные SVG-кольца в слое стола |
| Parallax-сцена | 4 слоя фона, `translate3d` от `pointermove` |
| Ambient-частицы | `<canvas>` с 60–90 частицами, цвет = палитра фракции |
| All In 1: holographic/specular | 3D-тилт карты от курсора + ездящий блик (`radial-gradient` по координатам мыши) |
| All In 1: dissolve | CSS/SVG-маска с шумом + `opacity` |
| VFX Graph | модуль `src/ui/vfx.ts`: кольца, искры, снаряды, слэши, тряска, hit-stop |
| Аудио | `src/ui/audio.ts`: WebAudio-синтез без файлов (в ТЗ звука нет → необязательное расширение) |

Файлы: `src/ui/vfx.ts`, `src/ui/audio.ts`, `src/ui/art.ts`, `src/ui/prototype.css`.

## 10. Арты карт: папки по фракциям и пайплайн (2026-09)

Единая точка хранения артов — `unity/EchoCitadel/Assets/Resources/Cards/<Faction>/<id>.png`:
`Aurites`, `Necrus`, `Terramorph`, `Pyromancer`, `Ethereal` (по 30), `Neutral` (6), `_Tokens` (7) —
всего 163 файла. Имя файла = id карты из Cards.json, поле `artworkPath` указывает на этот же путь,
поэтому Unity (`Resources.Load`) и прототип (`http://host:5173/art/<Faction>/<id>.png`, маунт в
`tools/serve.js`) читают один и тот же файл. В каждой папке лежат `README.md` (спецификация)
и `manifest.csv` (статус каждого файла + Midjourney-промпт; сводно — `docs/art_prompts.csv`).

Спецификация файла: 512×720 px, соотношение 5:7, PNG sRGB без альфы, без текста и рамок
(рамку и текст рисует UI). Сброшенные арты любого размера приводит к ТЗ
`python3 tools/generator/normalize_art.py` (центр-кроп + Lanczos, идемпотентно).
Прогресс: `python3 tools/generator/make_art_folders.py --check`.

Отрисовка: процедурная основа `src/ui/art.ts` (фон, рамка, мотив, foil) остаётся всегда,
поверх неё вставляется слой `<image href="/art/…">`; нет файла — слой молча отсутствует,
карта не ломается. В Unity тот же принцип: текстура из Resources поверх材质-слоёв рамки.

Полноэкранный живописный анимированный фон и честные жизни (итерация 2026-09b):
`#tableSurface` растянут на весь экран (inset:0, непрозрачная каменная подложка + золотая
инкрустация по кромке); задник ожил: медленный дрейф дальних слоёв (`driftFar/driftNear`,
