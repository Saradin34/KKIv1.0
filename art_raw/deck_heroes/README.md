ПОРТРЕТЫ ГЕРОЕВ КОЛОД · ОТДЕЛЬНЫЙ КАТАЛОГ
==========================================

Здесь хранятся только портреты героев, выбранных для конкретных колод. Каталог
изолирован от `art_raw/heroes/`: профильные аватары и существующие арты фракций
не переиспользуются и продолжают работать независимо.

В каждой подпапке героя положите файл с поддерживаемым расширением PNG, JPG,
JPEG, WebP или GIF, например `art_raw/deck_heroes/aurites-veteran/portrait.gif`.
Можно также положить файл прямо в `deck_heroes` под именем ID героя, например
`art_raw/deck_heroes/aurites-veteran.gif`. Регистр букв в имени ID не важен.
Для карточек архетипов лучше подходит вертикальная иллюстрация 2:3 или 4:5
высокого разрешения; лицо/главный силуэт располагайте ближе к центру.
Выбранный арт заменяет фракционный портрет целиком — кружка поверх карточки нет.
В бою этот же герой показывается в круглом медальоне.
Если в папке окажется несколько изображений, сервер и пайплайн сначала ищут
`portrait.*`, затем `00_main.*`, затем выбирают первый файл по имени.

Прототип отдаёт исходник напрямую по адресу `/deck-heroes/<id>`; GIF и
анимированный WebP/APNG воспроизводятся браузером. `npm run art:process`
создаёт статичный квадратный PNG 512×512 для Unity и копирует его в
`unity/EchoCitadel/Assets/Resources/DeckHeroes/<id>.png` (для анимации в Unity
нужен отдельный формат/пайплайн).
Пять базовых героев (доступны сразу):
- `Aurites/` — Стражи Света
- `Necrus/` — Культ Тени
- `Terramorph/` — Древний Конклав
- `Pyromancer/` — Легион Пламени
- `Ethereal/` — Духи Ветра

Герои за игровые монеты (по 2000 🪙):
- `aurites-veteran/` — Капитан Рассвета
- `necrus-herald/` — Вестник Бездны
- `terramorph-elder/` — Старейшина Рощи
- `pyromancer-sparkmaster/` — Мастер Искр
- `ethereal-stormkeeper/` — Хранитель Бури

Донатные герои (показаны в каталоге; списание недоступно до подключения оплаты):
- `aurites-ascendant/` — Златокрылый защитник
- `necrus-overlord/` — Повелитель Костей
- `terramorph-worldroot/` — Сердце Древнего Леса
- `pyromancer-inferno/` — Владыка Пламени
- `ethereal-starborn/` — Астральный странник

Выбирать можно только героев фракции колоды. Изображения намеренно не
создавались: добавьте свои файлы в соответствующие папки.
