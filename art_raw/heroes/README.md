ПАПКА АВАТАРОВ ГЕРОЕВ И КРУГОВ БЫСТРОГО ВЫБОРА
=================================================

Именно из этих папок берутся арты пяти круглых кнопок быстрого выбора фракции
в главном меню, аватары героев на столе и портреты в других экранах:

- Свет (Aurites)  → `art_raw/heroes/Aurites/`
- Тьма (Necrus)   → `art_raw/heroes/Necrus/`
- Земля (Terramorph) → `art_raw/heroes/Terramorph/`
- Огонь (Pyromancer) → `art_raw/heroes/Pyromancer/`
- Воздух (Ethereal) → `art_raw/heroes/Ethereal/`

Положите в нужную подпапку изображение `.png`, `.jpg`, `.jpeg` или `.webp`.
Для круглой иконки лучше квадратный портрет 512×512; имя файла может быть любым,
например `avatar.png`. Если файлов несколько, автоматически выбирается первый
по имени — основному арту дайте имя вроде `00_main.png`.

Прототип отдаёт файл через `/heroes/<Faction>` и сам масштабирует его в круг.
Папка `Neutral` используется для нейтрального героя, но не является кнопкой
быстрого выбора. Арты пользователь добавляет самостоятельно; здесь оставлены
только инструкции и каталоги.

Премиум-аватары (профиль → Персонализация, маленькие кружки):
- Архонт → `art_raw/heroes/arch/`
- Лунный Архонт → `art_raw/heroes/lunar/`
Эти же папки фракций используются для кружков аватаров в профиле.

ПРЕМИУМ-АВАТАРЫ (v3.11) — те же правила, id вместо фракции:
  arch.png     — «Архонт» ✧ (+3% XP)   (можно подпапкой arch/)
  lunar.png    — «Лунный Архонт» ☾ (+4% BP)
  dragon.png   — «Дракон Цитадели» 🐉 (+5% XP)
  phoenix.png  — «Феникс» 🔥 (+4% 🪙)
  runekeep.png — «Хранитель Рун» ❈ (+5% BP)
Кладите <id>.png в корень art_raw/heroes/ или первый кадр в подпапку art_raw/heroes/<id>/.
Бонус действует, когда аватар надет и получен (ach/набор).
