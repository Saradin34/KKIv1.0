ПАПКА АВАТАРОВ ГЕРОЕВ
======================
По одной подпапке на фракцию: Aurites, Necrus, Terramorph, Pyromancer, Ethereal, Neutral.
Положите внутрь подпапки любой png/jpg (имя любое, например avatar.png) — прототип сам найдёт
первый изображение и масштабирует его в круглый медальон героя на поле боя, в значки меню
и на экран конца игры. Генерировать арты самостоятельно не буду — папки ждут ваши файлы.
