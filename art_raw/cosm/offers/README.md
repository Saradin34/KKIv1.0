АРТЫ БУСТЕРОВ И ОФФЕРОВ — ПАПКА ДЛЯ ИЗОБРАЖЕНИЙ
=================================================

Кладите изображения в `art_raw/cosm/offers/` — пересборка прототипа не нужна.

Основные имена файлов:
- `booster.png` — обычный бустер: магазин, запас бустеров и окно вскрытия.
- `booster_premium.png` — мифический/премиум-бустер. Если файла нет, используется обычный арт.
- `pack_Aurites.png`, `pack_Necrus.png`, `pack_Terramorph.png`,
  `pack_Pyromancer.png`, `pack_Ethereal.png` — фракционные бустеры.
- `bundle11.png` — арт набора «10+1».

Для `booster.png` и `booster_premium.png` используйте портретный PNG не меньше
512×720 (5:7) с прозрачным фоном и без нарисованной внешней рамки: PNG и есть
сам пакет. Один и тот же арт показывается целиком в запасе, в магазине и на
крупной сцене вскрытия; прозрачность сохраняется, изображение не обрезается.
Для отдельных горизонтальных баннеров офферов можно использовать 768×432.
Поддерживаются PNG, JPG/JPEG и WebP; расширение и регистр имени обрабатываются
сервером. Для чистого эффекта пакета предпочтителен PNG с альфа-каналом.

Прототип подхватывает изображения по `/cosm/offers/<имя-файла-без-расширения>`.
Если арта нет, остаётся CSS-фолбэк. Unity-зеркало: `unity/EchoCitadel/Assets/Resources/Cosm/Offers/`.
