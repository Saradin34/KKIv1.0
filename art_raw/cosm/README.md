ПУТИ ДЛЯ БУДУЩИХ АРТОВ ЭХО-ЦИТАДЕЛИ
====================================

Изображения не входят в этот прототип и не создавались. Добавляйте свои файлы по указанным путям; сервер подхватит их без пересборки. Для `/cosm/` поддерживаются PNG, JPG/JPEG и WebP (регистр имени не важен). Если файла нет, интерфейс оставляет встроенный графический фолбэк.

## Боевой пропуск — универсальные иллюстрации наград

Код запрашивает `/cosm/bp/<имя>`, соответствующий файл кладётся сюда:

- `art_raw/cosm/bp/coins.png` — монеты.
- `art_raw/cosm/bp/booster.png` — обычный бустер.
- `art_raw/cosm/bp/premium_booster.png` — премиум-бустер.
- `art_raw/cosm/bp/cardback.png` — рубашка карты.
- `art_raw/cosm/bp/gems.png` — гемы.
- `art_raw/cosm/bp/foil_token.png` — фойл-жетон.
- `art_raw/cosm/bp/avatar.png` — аватар.

Рекомендуемый исходник — вертикальный PNG 512×720 с прозрачностью там, где она нужна. Иллюстрации универсальные: один файл используется для всех уровней с наградой этого типа.

## Ежедневные и еженедельные задания — иконки целей

Код запрашивает `/cosm/quests/<id>`; имена файлов должны совпадать с ID задания:

- `art_raw/cosm/quests/win_fac.png` — ежедневная победа нужной фракцией.
- `art_raw/cosm/quests/creatures.png` — сыгранные существа.
- `art_raw/cosm/quests/runes.png` — применённые руны.
- `art_raw/cosm/quests/pack.png` — открытый бустер.
- `art_raw/cosm/quests/w_win3.png` — три еженедельные победы.
- `art_raw/cosm/quests/w_runes.png` — еженедельно разыгранные руны.
- `art_raw/cosm/quests/w_creatures.png` — еженедельно разыгранные существа.
- `art_raw/cosm/quests/w_dmg.png` — нанесённый за неделю урон.

Рекомендуемый формат — квадратный PNG 256×256 с прозрачным фоном. Это небольшие иконки, не полноразмерные арты карт.

## Обложки колод

Для колоды `DeckId` предусмотрен путь `prototype/img/decks/DeckId.png`, то есть:

- `prototype/img/decks/Aurites.png`
- `prototype/img/decks/Necrus.png`
- `prototype/img/decks/Terramorph.png`
- `prototype/img/decks/Pyromancer.png`
- `prototype/img/decks/Ethereal.png`
- пользовательские/стартовые колоды: `prototype/img/decks/<deckId>.png`

Рекомендуется вертикальное изображение 512×720. Обложка показывается целиком, без обрезки. Для пользовательской колоды можно выбрать арт одной из входящих в неё карт; он служит запасным вариантом, если файл обложки отсутствует.
