# Значки боевого пропуска → `/cosm/bp/<id>`

PNG/JPG/WEBP с прозрачностью, рекомендуемо 128×128. Подхватываются автоматически
(пока файла нет — глиф-заглушка). Имя файла = тип награды:

| Файл | Награда |
|---|---|
| `coins.png` | Монеты |
| `gems.png` | Гемы |
| `booster.png` | Бустер |
| `premium_booster.png` | Премиум (мифический) бустер |
| `cardback.png` | Рубашка карт |
| `foil_token.png` | Фойл-жетон |
| `avatar.png` | Аватар |

Unity-зеркало: `unity/EchoCitadel/Assets/Resources/Cosm/Bp/`.
